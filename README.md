# REMIT — Atwick & Aldbrough

Minimal Streamlit app that pulls the REMIT / UoF table from
`https://thermaloutages.sse.com/gas-uof` and filters to the two SSE gas storage
facilities: **Atwick** and **Aldbrough**.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Works on Streamlit Community Cloud — point it at this repo and `app.py`.
